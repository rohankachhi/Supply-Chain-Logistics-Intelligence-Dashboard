# Supply Chain & Logistics Intelligence Dashboard – Executive View

## Project Overview

This project focuses on analyzing supply chain and logistics operations to evaluate business performance, monitor delivery efficiency, track shipping costs, and identify operational trends. An interactive Power BI dashboard provides executive-level insights through key performance indicators (KPIs) and visual analytics.

## Tools Used

- Microsoft Power BI
- Microsoft Excel
- DAX
- Data Cleaning & Transformation
- Data Visualization

## Key Features

- Supply chain performance monitoring
- Order and delivery status tracking
- Shipping cost analysis
- Inventory and logistics performance insights
- Executive KPI cards and interactive filters
- Operational trend analysis
